     $$\text{草鞋小厮} \xrightarrow{100功勋} \text{足轻头} \xrightarrow{300} \text{目付官} \xrightarrow{700} \text{部将} \xrightarrow{1500} \text{家老} \xrightarrow{3000} \text{城主} \xrightarrow{6000} \text{天下人}$$

   - **3 个新词**：严格按照 2024 新课标课本顺序推进；

   - 完成主命，信长亲自封赏功勋、贯高军资与战国出勤印章！

4. **📌 家长专属：一键对齐学校进度**
   - 顶部设有 **“📌 教学对齐”** 按钮。如果学校老师教得快，拖动滑块即可一键同步至学校当天的单词进度！

5. **⌨️ 实体键盘打字盲打优化（Keyboard-First）**
   - 专为配有妙控键盘/蓝牙键盘的 iPad 设计；
   - **智能容错**：敲击 `icecream` 自动命中 `ice cream`，敲击 `whats` 自动命中 `what's`，不因符号受阻；
   - **快捷键**：
     - `A ~ Z`：盲打拼词，拔刀挥砍
     - `空格键 / Enter`：随时重播标准纯正美音朗读
     - `Tab 键`：参悟密卷（获得下一个字母提示）
     - `Backspace`：退格删除
     - `Esc 键`：鸣金收兵返回天守
